# La Salette of Aurora, Inc. — Student Portal

A demo student portal website for **La Salette of Aurora, Inc.** (Brgy. Sta. Rosa, Aurora, Isabela, Philippines), built with plain HTML/CSS/JS — no build step required.

## Features
- Student sign-in (demo auth, front-end only)
- Dashboard with announcements, events & academic snapshot
- Grades & report card view
- Weekly class schedule
- Campus Ministry section (prayers, First Friday Mass, Rosary Crusade, SELG/SSLG)
- Announcements feed (sourced from the official Campus Ministry Facebook page)
- School history, vision, mission & core values with photo gallery
